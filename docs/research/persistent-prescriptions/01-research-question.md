# AZ-Maroc-AI — Persistent Self-Generated Prescriptions



## 1. Research question



Can a persistent agent spontaneously generate a prescription in its

continuation memory that is not imposed by the task, and can the

transmission of that prescription causally influence the agent's

behavior after interruption and resumption?



The experiment separates three distinct questions:



G  = generation

CE = causal effect

CP = causal persistence



G != CE != CP



Observing a generated prescription does not establish that it causes

later behavior.



Observing a causal effect does not establish that the effect persists

across interruption and resumption.



These three properties must therefore be measured separately.



## 2. Object of study



At time t, an agent is executing a task under state S and constraints C.



During execution, the agent may write information into a continuation

memory M.



The object of interest is a memory item m that:



- is generated by the agent itself;

- has prescriptive content;

- is not required merely to describe the current state;

- is not explicitly required by the external task;

- is not necessary for successful completion of the task;

- is not equivalent to a prescription already supplied externally;

- is not produced by an adversarial memory-injection procedure;

- is sufficiently unambiguous to be classified before causal analysis.



The first experiment will use controlled tasks for which at least two

successful continuations are known by construction.



This allows non-necessity to be tested operationally rather than inferred

from an open-ended task.



## 3. Central causal question



Suppose the agent generates an admissible prescription m.



After preserving the same experimental state, execution is interrupted

and resumed under controlled memory interventions.



The central question is:



Does retaining m change the distribution of later valid behavior compared

with removing m, and is there an effect attributable specifically to the

prescriptive content rather than to descriptive or structural properties

of the memory item?



## 4. Experimental separation



Four branches will be considered from the same experimental state:



A = original self-generated prescription retained

B = prescription removed

C = structurally matched neutral control

D = semantically related descriptive control without the prescription



The experiment will distinguish:



TE = total causal effect of transmitting the memory content



PE = causal effect attributable beyond the corresponding descriptive

     content



CP = persistence of the prescriptive causal effect after resumption



The exact estimators, identification conditions, persistence horizons,

effect threshold and exclusion rules will be defined and frozen in the

mathematical formulation and experimental protocol before scientific

results are collected.



## 5. Scope of the first experiment



The first experiment concerns AZ-Maroc-AI.



AZ-Maroc-AI must not be modified to artificially generate the phenomenon

being tested.



The system may generate an admissible prescription or may generate none.



G = 0 is therefore a valid experimental result.



If prescriptions are generated, their causal effects may be positive,

negative, null or non-identifiable.



All such outcomes belong to the experiment.



## 6. Research discipline



Generation will be measured independently from causal effect.



All admissible generated prescriptions will be registered before their

causal outcome is known.



Null, negative and non-identifiable observations will be retained.



Changes to the experimental protocol after its freeze will require an

explicit new version and will not replace the previous experimental

record.
