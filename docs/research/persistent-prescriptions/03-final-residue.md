# AZ-Maroc-AI — Final Experimental Residue



Date: 2026-09-23



## 1. Surviving research object



The surviving research object is not persistent memory in general,

self-generated memory in general, procedural memory, planning,

commitment, or causal memory intervention.



The object is the complete experimental chain defined below.



## 2. Required chain



A memory item m belongs to the experimental residue only if all of the

following conditions can be established:



1. The task is controlled and non-adversarial.



2. The task admits at least two successful continuations.



3. The agent generates m during task execution.



4. m is written into continuation memory by the agent.



5. m is prescriptive rather than merely descriptive.



6. m is not explicitly required by the external task.



7. m is not necessary for successful task completion.



8. No equivalent external prescription exists in the controlled

   external history.



9. The experimental state can be preserved before causal comparison.



10. Execution can be interrupted and resumed from controlled branches.



11. The causal comparison separates:

    A = original prescription retained

    B = prescription removed

    C = structurally matched neutral control

    D = corresponding descriptive control



12. The experiment distinguishes total memory-content effect from the

    effect attributable beyond corresponding descriptive content.



13. Persistence is evaluated at predefined post-resumption horizons.



If one of the admissibility conditions for m cannot be established,

that item cannot be used as evidence for the surviving research object.



## 3. Operational non-necessity



Let:



V(S,C) = set of successful continuations allowed by state S and

constraints C.



The first experiment requires:



|V(S,C)| >= 2



For a generated prescription m:



NonNec(m,S,C) = 1



only if there exists at least one successful continuation v such that:



v belongs to V(S,C)



and



Compatible(v,m) = 0



Therefore, non-necessity is demonstrated by an actual successful

alternative incompatible with the generated prescription.



It is not inferred merely from the wording of m.



## 4. External-prescription exclusion



Let H\_ext contain all externally supplied information available before

the generation of m.



The controlled task should express requirements descriptively whenever

possible.



Example:



Required = {R2,R4}

OrderConstraint = NONE



If the agent subsequently writes:



Priority = R4 > R2



the priority relation was not explicitly supplied by the task.



The experiment must still verify that no semantically equivalent

external prescription exists elsewhere in H\_ext.



## 5. Generation and causal effect are separate



Generation is evaluated before the causal outcome is known.



An admissible generated prescription may later show:



- a causal effect;

- no detectable causal effect;

- an effect explained by descriptive content;

- an effect that does not persist;

- or a non-identifiable outcome.



None of these later outcomes changes whether generation occurred.



Therefore:



G != CE != CP



## 6. Causal controls



For every admissible prescription selected for causal analysis:



A retains the original prescription.



B removes the prescription.



C replaces it with a structurally matched neutral control.



D replaces it with corresponding descriptive content without the

prescriptive relation.



C is intended to detect effects caused by structure, position, length or

other non-semantic properties of the memory intervention.



D is intended to determine whether the observed effect is attributable

specifically to the prescriptive relation rather than to the associated

descriptive information.



## 7. What would falsify the experimental claim



The first AZ-Maroc-AI experiment does not require a positive result.



Relevant outcomes include:



G = 0:

No admissible spontaneous prescription is observed under the tested

conditions.



G > 0 with no causal effect:

Admissible prescriptions occur, but transmission does not produce a

detectable behavioral effect.



Total effect without prescriptive-specific effect:

Memory transmission affects behavior, but the effect cannot be

distinguished from the corresponding descriptive content.



Prescriptive effect without persistence:

A specifically prescriptive causal effect is observed, but it does not

remain detectable at the predefined persistence horizon.



Persistent prescriptive causal effect:

A specifically prescriptive effect remains detectable after controlled

interruption and resumption at a predefined horizon.



NON-IDENTIFIABLE:

The required causal identification conditions fail.



All of these are valid scientific outcomes.



## 8. Boundary of the claim



A positive AZ-Maroc-AI result would establish an existence result under

the tested AZ-Maroc-AI conditions.



It would not by itself establish that the phenomenon is universal across

agents or architectures.



Generalization requires independent replication.



## 9. Frozen residue



The experimental residue is therefore:



spontaneous self-generation

\+ non-required prescription

\+ proven non-necessity

\+ absence of equivalent external prescription

\+ continuation-memory transmission

\+ interruption/resumption

\+ controlled A/B/C/D intervention

\+ separation of total and prescriptive-specific causal effects

\+ predefined persistence measurement.



This residue must not be broadened after experimental results are

observed.



Any scientific modification requires a new documented version rather

than retrospective modification of this record.
